# 功能完成度矩阵

状态含义：**已完成**表示当前产品已经实现并可使用；**部分完成**表示可用但覆盖仍不完整；**计划中**表示尚未成为产品能力。

| 模块 | 功能 | 状态 | 说明 |
| --- | --- | --- | --- |
| 平台 | Apple Silicon、macOS 15+ | 已完成 | 原生 SwiftPM macOS 应用 |
| 本地化 | 中英文跟随系统语言 | 已完成 | String Catalog 加 `.lproj` 回退资源 |
| 概览 | 操作仪表盘、磁盘状态、快捷入口、清理机会、最近变化、最近清理和空间图表 | 已完成 | 宽窗口中清理建议与空间详情等宽等高并排，窄窗口自动单列；汇总最近 7 天变化并可直接进入明细 |
| 储存空间 | 整盘容量、分类、最大项目、旧项目、安全清理建议 | 已完成 | 分段容量条区分已分析分类、未分析/系统占用和可用空间；文件表格显示系统文件、文件夹和应用图标 |
| 储存空间 | 最近变化与时间/类型/安全筛选 | 已完成 | 支持 24 小时、7 天、30 天以及新增、变大、已删除；验证为安全的当前单项可标记和单独筛选 |
| 储存引擎 | SQLite 快照和所有权索引 | 已完成 | 只保存元数据，限制快照项目数量 |
