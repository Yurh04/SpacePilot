# 功能完成度矩阵

状态含义：**已完成**表示当前产品已经实现并可使用；**部分完成**表示可用但覆盖仍不完整；**计划中**表示尚未成为产品能力。

| 模块 | 功能 | 状态 | 说明 |
| --- | --- | --- | --- |
| 平台 | Apple Silicon、macOS 15+ | 已完成 | 原生 SwiftPM macOS 应用 |
| 本地化 | 中英文跟随系统语言 | 已完成 | String Catalog 加 `.lproj` 回退资源 |
| 概览 | 操作仪表盘、磁盘状态、快捷入口、清理机会、最近清理和空间图表 | 已完成 | 优先展示可执行操作；已分析总量不冒充整个磁盘总量，图表在窄窗口自动单列 |
| 储存空间 | 分类、最大项目、旧项目、安全清理建议 | 已完成 | 基于本地已索引和已分析内容；文件表格显示系统文件、文件夹和应用图标 |
| 储存引擎 | SQLite 快照和所有权索引 | 已完成 | 只保存元数据，限制快照项目数量 |
| 储存引擎 | FSEvents 小范围增量刷新 | 已完成 | 使目录缓存失效并刷新受影响模块 |
| 储存引擎 | 零成本完整统计所有磁盘数据 | 计划中 | 不作此承诺，受权限和系统数据限制 |
| 应用程序 | 快速获取已安装应用清单 | 已完成 | `/Applications` 和当前用户的 Applications 目录 |
| 应用程序 | 按需深度分析关联文件 | 已完成 | 启动时不深度分析每个应用 |
| 应用程序 | 证据、置信度、所有权和风险 | 已完成 | 默认选择策略较保守 |
| 应用程序 | 关联项分组和 Finder 定位 | 已完成 | 包含原生双击行映射 |
| 应用程序 | 重置和选择性完整卸载 | 已完成 | 用户选择需要处理的准确路径 |
| 应用程序 | 大范围第三方应用规则库 | 部分完成 | 只添加有证据和测试的规则；豆包已使用 Bundle ID 与签名 Team 精确匹配 |
| 开发工具 | Xcode/Simulator/Homebrew/npm/Gradle/pip | 已完成 | 采用已知位置规则 |
| AI | ChatGPT 与 Codex 统一产品族 | 已完成 | 应用、数据、Skill 和 Plugin 合并统计 |
| AI | Claude 深度本地数据分析 | 已完成 | 只分析本地元数据 |
| AI | Ollama/OpenCode 和任意 AI 工具 | 部分完成 | 不同工具目前覆盖深度不同 |
| AI 管理 | 本地/远程 Agent、Plugin、Skill、CLI 工具 | 已完成 | 按 Agent、所有者和范围分组，展示可信安装证据与覆盖诊断 |
| AI 管理 | 用户批准项目中的 AI 资产 | 已完成 | 只扫描明确批准的有界项目根目录，拒绝越界和失效配置 |
| AI 管理 | 版本检查和受控更新 | 已完成 | 仅固定工具定义和预定义包管理器命令可执行；需用户选择并确认，冲突或不支持项保持只读 |
| Skill | 全局/Codex/Claude/Plugin/系统/项目范围 | 已完成 | 检测重复、冲突、所有者和覆盖关系 |
| Skill | 在不同 Agent 目录间移动 Skill | 不计划 | 明确的产品安全决策 |
| Plugin | 清单、组件、Skill 和诊断 | 已完成 | Plugin 管理缓存保持只读 |
| 清理 | 逐项选择和敏感项确认 | 已完成 | Managed 项不能直接清理 |
| 清理 | 身份复核并移到废纸篓 | 已完成 | 不提供永久删除 |
| 清理 | 操作历史和已验证释放空间 | 已完成 | 本地存入 SQLite |
| 隐私 | 完全本地的元数据分析 | 已完成 | 不索引对话和日志正文 |
| 权限 | 在权限不完整时继续分析 | 已完成 | 准确度仍取决于授权范围 |
| 分发 | 本地 `.app` 和 ZIP 打包 | 已完成 | ad-hoc 签名仅供开发测试 |
| 分发 | 经过公证的公开测试版 | 计划中 | 需要 Developer ID 和公证凭据 |

状态发生变化时，应在同一个提交中更新本文档和 `docs/PROJECT_STATUS.md`。新增子系统时，还应增加对应测试并更新代码地图。
