# 全局可点击元素悬停反馈设计

日期：2026-10-01  
状态：待用户审阅  
产品：SpacePilot for macOS 15+，Apple Silicon

## 目标

为 SpacePilot 所有可点击元素提供一致、克制且符合 macOS 习惯的悬停反馈，让用户在点击前能够判断哪些区域可交互，同时不把纯展示内容伪装成入口。

成功标准：

- 光标进入可点击区域后，在不改变布局的前提下出现可感知的视觉反馈；
- 原生控件继续保留系统行为，不叠加冲突的自定义效果；
- 自定义卡片、纯样式按钮、列表行和表格行具有一致的视觉语言；
- 选中、按下、禁用、键盘焦点和悬停状态之间有明确优先级；
- 浅色、深色模式和窄窗口均正常工作。

## 非目标

- 不给普通文字、指标、图表、信息卡片或不可点击行增加悬停背景；
- 不把 macOS 箭头光标改成网页式手形光标；
- 不用缩放、位移、阴影跳变等会造成布局抖动的效果；
- 不替换 SwiftUI 原生 `Button`、`List`、`Table`、`Picker` 或侧边栏选择模型；
- 不改变现有点击、双击、右键菜单、键盘导航、清理确认或 Finder 定位行为。

## 交互规范

### 状态优先级

从高到低为：

1. 禁用；
2. 选中；
3. 按下；
4. 键盘焦点；
5. 悬停；
6. 默认。

悬停不能覆盖选中行的系统高亮，也不能让禁用控件看起来可用。按下状态由原生按钮样式负责，悬停背景只作为点击前提示。

### 视觉效果

- 自定义交互面使用 `Color.accentColor` 的低透明度背景，目标不透明度为 `0.07...0.10`；
- 必要时增加同色、低透明度的 1 pt 描边，但不为每个普通文本按钮强制加边框；
- 圆角由调用方按组件形态指定，默认 8 pt；
- 使用约 120 ms 的 `easeOut` 动画；
- 不改变控件尺寸、内边距或对齐，因此不会触发布局跳动；
- 深浅模式只使用系统语义颜色，不新增固定浅色或深色调色板。

## 架构

采用“原生优先 + 统一补充”的混合方案。

### SwiftUI 自定义交互面

在 `Sources/SpacePilot/Views/Shared/InteractiveHover.swift` 增加共享能力：

- `InteractiveHoverModifier` 保存局部 `isHovering` 状态；
- `View.interactiveHover(isEnabled:cornerRadius:)` 作为调用入口；
- 修饰器只负责悬停背景、描边和动画，不自己处理点击；
- 调用方必须本身已经是 `Button`、可选择行或具有明确点击动作；
- 禁用状态通过显式 `isEnabled` 或环境 `isEnabled` 抑制效果；
- `contentShape` 与可点击区域保持一致，不能扩大到相邻的非交互内容。

适用范围包括：

- `.buttonStyle(.plain)` 或 `.buttonStyle(.borderless)` 的自定义按钮；
- 概览、开发与 AI 等页面中的可点击卡片入口；
- 自定义侧边栏行和带手势的可点击行；
- 图标按钮在系统样式没有足够可见反馈时的内容区域。

标准 `.bordered`、`.borderedProminent`、工具栏按钮、菜单按钮、Picker、Toggle 和系统侧边栏选择继续依赖系统悬停反馈，避免双重背景。

### 原生 List 和 Table 行

SwiftUI `List` 和 `Table` 的底层为 `NSTableView`，单纯给单元格添加 `.onHover` 会造成多列高亮不完整。因此在 `Sources/SpacePilot/Views/Shared/NativeTableHover.swift` 增加窄范围 AppKit 互操作：

- 通过与现有 `NativeTableDoubleClickAdapter` 相同的邻近表格发现方式定位底层 `NSTableView`；
- 安装 `NSTrackingArea` 或等价的鼠标移动观察，不替换 table 的 target/action；
- 根据鼠标坐标计算当前可见行，只更新旧行和新行；
- 只为未选中、非 group/header、可交互的普通行设置低透明度背景；
- 光标离开、视图拆除、数据刷新、滚动导致行复用或选择改变时清除临时背景；
- 原生选中颜色始终优先，不能被悬停色覆盖；
- 适配器不改变 `clickedRow`、双击映射、上下文菜单或 Finder 定位逻辑。

公开入口为 `View.nativeTableHoverHighlight(...)`。需要排除标题行或不可点击行时，由调用方提供行是否可交互的映射闭包。原生分组列表必须继续使用可见行映射，不能把 `clickedRow` 直接当成扁平数据索引。

## 页面覆盖

### 顶层与概览

- 主侧边栏继续使用系统 selection hover；
- 概览的清理、快速查看、最近变化、历史和权限入口分别按其现有按钮样式接入；
- 纯展示的储存状态、容量环、分类条和指标不增加效果。

### 储存空间与应用程序

- 储存分类列表、最大项目、旧项目、最近变化表格行；
- 应用列表、关联文件列表、清理与 Finder 操作；
- 已选中表格行保持系统选择色，悬停只作用于其他可点击行。

### 开发与 AI

- Agent、MCP、Skill、Plugin、CLI 和其他 AI 工具的侧边栏与表格行；
- Agent 概览中的自定义可点击卡片；
- 只读指标、健康说明和不可操作的资产摘要不高亮。

### 清理历史、确认与设置

- 清理历史中可以展开、选择或定位的行；
- 清理确认中的可选择项目；
- 设置页继续优先使用系统 Button、Toggle、Picker 的原生反馈。

## 可访问性与输入方式

- 悬停效果只是额外提示，不能成为识别可点击性的唯一方式；文字、图标、按钮样式和可访问性角色仍需完整；
- 键盘焦点环、方向键选择、Return/Space 激活必须继续工作；
- VoiceOver 语义不因装饰背景发生变化；
- `Reduce Motion` 开启时取消或显著缩短悬停动画；
- 高对比度模式下使用系统语义色并保留足够边界，不写死颜色值；
- 鼠标、触控板和键盘操作都不能互相抢占事件。

## 性能与生命周期

- SwiftUI 修饰器只保存一个布尔状态，不进入全局 `AppModel`；
- 原生表格适配器只处理鼠标所在行变化，不遍历完整数据集；
- 仅更新旧悬停行和新悬停行，避免每次鼠标移动刷新所有可见行；
- 适配器拆除时必须移除 tracking area、观察和临时行背景；
- 页面切换、普通启动和悬停不能触发扫描、投影重建或持久化写入。

## 测试

### 共享 SwiftUI 修饰器

- 启用时进入/离开会切换悬停视觉状态；
- 禁用时不显示悬停状态；
- Reduce Motion 分支不执行常规动画；
- 修饰器不改变视图理想尺寸。

### 原生表格适配器

- 鼠标坐标准确映射到可见普通行；
- group/header 和调用方标记为不可交互的行不高亮；
- 选中行不被悬停背景覆盖；
- 从一行移动到另一行只清除旧行并设置新行；
- mouse-exited、数据刷新、滚动复用和 dismantle 都会清理状态；
- 与 `NativeTableDoubleClickAdapter` 同时安装时，点击、双击和原有 target/action 转发不变。

## 验收标准

- 所有明确可点击的自定义入口在悬停时有一致反馈；
- 所有可交互 List/Table 普通行有整行反馈；
- 纯展示内容不高亮；
- 禁用与选中状态不会被悬停覆盖；
- 不发生布局移动、表格选择丢失、双击失效或主线程扫描；
- 自动化测试、发布检查和五个主页面的真实运行时检查均完成。
