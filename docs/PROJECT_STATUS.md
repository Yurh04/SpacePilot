# 项目开发状态

最后更新：2026-09-09
当前预览版本：0.1.3
支持平台：Apple Silicon、macOS 15+

## 当前阶段

SpacePilot 已进入 0.1.3 内测稳定阶段。核心扫描、持久化索引、增量刷新、应用管理、AI 管理、选择性清理、中英文界面和主要交互流程均已完成；本阶段补齐权限恢复入口、变化摘要、筛选可读性、应用分析状态和窄窗口回归。当前重点是扩大真实环境验证并准备经过正式签名的外部测试版本。

## 已实现

- 原生 SwiftUI macOS 应用，中英文跟随 macOS 系统语言。
- 概览、储存空间、应用程序、开发与 AI、清理历史五个主要模块。
- 概览已升级为操作仪表盘：显示磁盘健康状态、可用空间、安全清理建议和已分析空间，并提供清理、最大项目、最近变化、应用占用、重新扫描和清理历史快捷入口；图表退居空间详情区域。
- 概览首屏已压缩为连续的信息层级：磁盘指标不再各自套卡片，快捷操作保持紧凑；宽窗口中清理建议与空间详情以等宽等高卡片并排，最近清理并入左卡底部，窄窗口自动改为上下布局。
- 概览直接汇总最近 7 天的新增、变大、释放、可用空间变化与可安全清理空间；覆盖范围不足时显示不可访问文件夹数量，并可直接打开 macOS 完全磁盘访问设置。
- 空间详情使用带直接数值的紧凑容量环和比例条分类列表；类别名称与容量采用正文级字号，不再依赖密集坐标轴读取数据。
- 快速应用清单覆盖标准应用目录中的套件子目录，并通过 Spotlight 补充已注册的独立更新器、Agent 和工具链应用；嵌套 helper、构建产物和重复 Bundle 不会作为独立应用重复显示。
- 应用详情重新分析期间保留现有列表投影，完成后原位更新，不会因列表重建而跳回顶部。
- 应用详情显示关联文件分析进度和本次运行中的上次完成时间，不再只用遮挡内容的居中转圈表达状态。
- 窄窗口不再用 `1_000 pt` 的根内容宽度向两侧溢出；主导航、应用列表、储存分类和详情工作区会在有界范围内协同收缩，应用统计卡在空间不足时改为纵向排列。
- 储存空间的文件表格显示 macOS 系统文件图标；文件夹使用 Finder 文件夹图标，能够解析应用归属的容器会显示对应应用图标。
- 储存空间顶部使用整盘分段容量条和图例，明确区分已分析分类、未分析/系统占用和可用空间；未归因差额不再伪装成“0 项”的系统分类。
- 储存空间内部的已分析分类栏保持稳定宽度，切换最大项目、旧项目和最近变化时不会被筛选器挤窄。
- 最大项目、旧项目和最近变化共用常驻的模式导航栏和固定操作位；切换最近变化时导航不会横向跳动，时间、类型和安全性筛选在下一行响应式排列。
- 最近变化的时间范围、变化类型和可清理性筛选均显示明确标题，并提供稳定的无障碍标识，避免多个“全部”含义不清。
- 储存空间的最大项目、旧项目和最近变化表格支持点击列头切换升序、降序，排序后的行仍可正确双击在 Finder 中定位。
- 储存空间新增“最近变化”：支持 24 小时、7 天、30 天以及新增、变大、已删除筛选；单项变化达到 100 MiB 后单独显示，小变化按目录聚合，1 GiB 以上重点提示。经过风险模型验证的当前单项会显示“可安全清理”，并可切换为仅查看这些项目。
- 最近变化基线、31 天事件、磁盘可用空间采样和覆盖缺口保存到 SQLite；FSEvents 从持久化游标回放应用关闭期间的事件，完整扫描会校准基线。
- 版本化应用关联知识库、Bundle/容器/Team 证据、Spotlight 候选发现、置信度和所有权标记。
- Chrome 使用精确 Bundle ID 与签名 Team 规则关联 `Google/Chrome` 支持数据、缓存和产品标记；不把共享的 Google Updater 主目录整体算作 Chrome 专属空间。
- 应用详情会在 macOS 当前用户临时区的 `C/T/X` 一级目录中查找与主应用或签名组件 Bundle 命名空间精确匹配的缓存、helper 和代码签名副本，不递归扫描整个 `/private/var`。
- 应用关联文件分组、逐项选择、重置、完整卸载预览、文件图标和双击在 Finder 中显示。
- 豆包应用族使用精确 Bundle ID 与签名 Team 规则识别专属支持数据和缓存，相似标识不会命中。
- SQLite 元数据快照和索引、目录大小缓存、启动恢复、FSEvents 失效处理和按范围后台刷新。
- ChatGPT 与 Codex 产品族合并；Claude 深度分析；Ollama 和 OpenCode 基础空间统计。
- 以本地/远程 Agent 为中心展示应用、CLI、全局和 Agent 专属 Skill、Plugin、Plugin 提供的 Skill、冲突检测和安装证据。
- 仅扫描用户明确批准的项目目录，并按项目和所有者分组其中的 AI 配置、Skill 与 Plugin；越界、重复或失效目录会被拒绝或明确报告。
- 对固定定义且具有可信安装证据的 AI 工具检查版本，并仅通过预定义包管理器命令执行用户确认的更新；不支持或证据冲突的项目保持只读。
- 识别 Xcode/Simulator、Homebrew、npm、Gradle 和 pip 的常见开发储存位置。
- 选择性清理、路径保护、敏感项确认、文件身份复核、移到废纸篓、结果验证和历史记录。
- 限制快照保留项目数量，并把投影工作移出主线程，解决此前超大快照导致的内存问题。

## 部分完成或仍需扩大覆盖

- 应用关联规则有意保持保守，还需为更多应用族和共享容器补充经过验证的规则；当前临时区发现只覆盖名称中保留准确 Bundle 命名空间的项目。
- 完整磁盘分析依赖 macOS 权限；不可访问路径必须继续明确显示为覆盖范围不足。
- 储存分类代表 SpacePilot 已分析的本地数据，不能等同于 macOS 显示的全部“系统数据”；界面会把无法映射到可读索引路径的差额单列为“未分析/系统占用”。
- 不同 AI 产品的支持深度不同：ChatGPT/Codex 和 Claude 比 Ollama、OpenCode 及新发现工具更深入。
- 本地应用包和 ZIP 可以生成，但正式公开分发仍需配置 Developer ID 签名和 Apple 公证。
